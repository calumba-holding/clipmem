# Clipboard Memory Troubleshooting

If `clipmem recall` is weak or empty:

1. widen the time window
2. add or remove source filters
3. switch to `timeline` for chronology
4. switch to `search` for a literal query

If exact text is unavailable:

- use `clipmem get <snapshot_id> --format json`
- report surfaced metadata honestly
- mention `clipmem export` for binary-only content
